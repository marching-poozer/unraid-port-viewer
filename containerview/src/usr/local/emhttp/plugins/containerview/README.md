**Container View**

Groups and filters the Docker Containers list and the Dashboard's Docker tile by category, taken from the `net.unraid.docker.category` label (comma-separated) or from category rules for containers without one. Compose stacks show as collapsible rows; groups and stacks have their own action menus; a filter bar finds containers by name, image, stack, port or IP and can update the listed ones. Settings are in the cog beside Basic/Advanced View on the Docker tab.
